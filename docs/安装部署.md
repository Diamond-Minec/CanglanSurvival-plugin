# 沧蓝工坊 · 整合生存包 —— 安装部署

> 适配 **Paper 1.21.11**（Java 21 及以上）　作者：**沧蓝工坊**

## 一、安装（3 分钟）

1. 下载 **Paper 1.21.11**：<https://papermc.io/downloads/paper>
2. 安装 **Java 21 或更高**（推荐 Java 21 LTS）
3. 把 `dist/CanglanSurvival-1.0.0.jar` 放进服务器的 `plugins/` 文件夹
4. 启动服务器：
   ```bash
   java -Xms1G -Xmx2G -jar paper.jar --nogui
   ```
5. 启动后插件会自动生成：
   ```
   plugins/CanglanSurvival/
   ├── config.yml        # 总配置（全中文注释）
   ├── modules.yml       # 21 个模块的开关
   ├── players.yml       # 每个玩家的单独授权
   ├── claims.yml        # 领地数据（立体领地）
   ├── notices.yml       # 公告内容
   ├── shop.yml          # 商店商品
   ├── economy.yml       # 金币数据
   ├── stats.yml         # 统计数据
   ├── homes.yml         # 家园数据
   ├── warps.yml         # 地标数据
   ├── permissions.yml   # 权限组与节点
   └── auth.yml          # 登录验证数据
   ```
6. 进服后给自己 OP：控制台输入 `op 你的名字`，然后用 `/cl` 查看模块列表。

> 第一次进服默认需要 `/register <密码> <确认密码>` 注册（登录验证模块），
> 不想要可以 `/cl disable auth` 关掉。

## 二、必改的几项配置

打开 `plugins/CanglanSurvival/config.yml`：

```yaml
server-name: "&b&l沧蓝工坊 &f生存服"   # 也可以用 /servername "名字" 在游戏内改
prefix: "&b&l沧蓝工坊 &7» &f"          # 消息前缀

claims:
  default-limit: 1     # 每人默认领地数量
  max-size: 64         # 单块领地单边最大 64 格
  max-height: 64       # 单块领地最大高度 64 格

rtp:
  min-distance: 200    # 随机传送距离
  max-distance: 3000

economy:
  starting-balance: 100.0   # 新玩家初始金币
```

改完在游戏里输入 `/cl reload all` 生效，不用重启。

## 三、服务器列表 MOTD

插件里的 `/servername` 只改**插件内部显示**的服务器名（TAB、计分板、菜单标题）。
多人游戏列表里那行 MOTD 属于 `server.properties`：

```properties
motd=沧蓝工坊 生存服\n1.21.11 原版生存 | 领地 | 商店 | 每日签到
```

改完需要**重启服务器**。

## 四、性能建议

- 21 个模块全开时内存占用约 **150~300 MB**，小服 `-Xmx1G` 足够
- 计分板 / TAB 每秒刷新一次，人数很多（100+）时可把 `scoreboard.enabled` 或 `tab` 关掉
- 领地是按范围判定的，不存储方块，几千块领地也不卡

## 五、常见问题

| 问题 | 原因 / 解决 |
| --- | --- |
| `/unban-ip` 提示未知指令 | Bukkit 里解封 IP 的指令是 **`/pardon-ip <IP>`**，解封玩家用 `/unban <玩家>` |
| 中文指令不生效 | 中文写法仍然支持（如 `/公告`），但**提示里统一用英文名**；不确定就用 `/cl info <模块>` 看指令表 |
| 指令没有任何反应 | 可能被 `/cl disable <模块>` 全局关闭了，用 `/cl list` 看开关状态 |
| 玩家被踢：`multiplayer.disconnect.unverified_username` | `server.properties` 里的 `online-mode` 被写坏了，改成 `online-mode=false`（离线服）并保存为 **无 BOM 的 UTF-8** |
| 老版本按区块存的领地 | 启动时会自动转成 16×16×全高的立体领地，不会丢 |
| 换服迁移 | 整个 `plugins/CanglanSurvival/` 文件夹拷走即可（全是 YAML 明文） |

## 六、卸载

1. 停服
2. 删除 `plugins/CanglanSurvival-1.0.0.jar`
3. （可选）删除 `plugins/CanglanSurvival/` 数据文件夹
