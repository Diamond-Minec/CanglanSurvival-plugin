# 沧蓝工坊 · 整合生存包 —— 指令速查

> 所有提示里使用**英文指令名**；中文写法仍然可用（如 `/公告` → `/notice`）。
> `/cl` 的子指令中英都认：`/cl list` = `/cl 列表`。

## 一、服主指令（`/cl`）

| 指令 | 说明 |
| --- | --- |
| `/cl` `/cl help` | 帮助 |
| `/cl list` | 21 个模块与开关状态 |
| `/cl info <模块>` | 模块详情、指令、权限节点 |
| `/cl status` | TPS / 内存 / 模块统计 |
| `/cl my` | 你自己能用的模块 |
| `/cl enable <模块>` | 启用模块（立即生效） |
| `/cl disable <模块>` | 禁用模块（监听器与任务一并卸载） |
| `/cl reload <模块>` / `/cl reload all` | 重载配置 |
| `/cl player <玩家> list` | 查看该玩家的单独授权 |
| `/cl player <玩家> allow <模块>` | 单独允许 |
| `/cl player <玩家> deny <模块>` | 单独禁止（优先级最高） |
| `/cl player <玩家> reset <模块>` | 恢复默认 |
| `/servername "名字"` | 修改服务器名称（`/servername` 查看、`/servername reset` 恢复） |

## 三、领地规则速记

- 圈地：`/claim pos1` 站在一角 → 走到对角 → `/claim pos2` → `/claim create 我的家`
- 尺寸：**单边最多 64 格、最高 64 格、体积最多 262144 格**
- 别人在你领地里不能：挖方块、放方块、开箱子/熔炉、拉门按按钮、倒液体、取液体、炸方块、破坏画
- 领地内默认禁 PvP（`claims.pvp-in-claims: true` 可开）
- 想放朋友进来：`/claim trust 朋友名`（在这块领地范围内执行）
- 数量上限：默认 1 块，用权限 `canglan.claim.limit.5` 提到 5 块
- 管理员无视领地：权限 `canglan.claim.bypass`

## 五、权限节点

| 节点 | 默认 | 说明 |
| --- | --- | --- |
| `canglan.admin` | OP | 全部管理权限 |
| `canglan.module.<模块ID>` | 见 README | 使用某个模块（`perm`/`punish`/`monitor` 默认仅 OP） |
| `canglan.claim.bypass` | OP | 无视领地保护 |
| `canglan.claim.limit.<N>` | 无 | 领地数量上限 N 块 |
| `canglan.home.limit.<N>` | 无 | 家园数量上限 N 个 |
| `canglan.economy.admin` | OP | `/eco` 发放扣除 |
| `canglan.punish.admin` | OP | 警告 / 踢出 / 封禁 |
| `canglan.chat.admin` | OP | 禁言 / 清屏 |
| `canglan.report.admin` | OP | 查看举报 |
| `canglan.monitor.notify` | OP | 低 TPS 提醒 |
| `canglan.auth.bypass` | OP | 跳过登录验证 |
